Concordancia clasificador ↔ cardiólogo

Estas métricas cuantifican qué tan bien las predicciones del clasificador MSM-SC + XGBoost coinciden con el juicio de {{ medico.nombre_completo }}. Se derivan de sus semáforos por ventana: verde = acuerdo total (clasificación correcta según el cardiólogo), amarillo = acuerdo parcial (dudosa), rojo = desacuerdo (incorrecta).

Métricas de concordancia derivadas
$$\text{Accuracy}_{estricta} = \frac{N_{verde}}{N_{total}} \times 100\%$$ $$\text{Accuracy}_{permisiva} = \frac{N_{verde} + N_{amarillo}}{N_{total}} \times 100\%$$ $$\text{Error rate} = \frac{N_{rojo}}{N_{total}} \times 100\%$$
Donde: $N_{color}$ = número de ventanas con veredicto de ese color emitido por el cardiólogo; $N_{total} = N_{verde} + N_{amarillo} + N_{rojo}$ = total de ventanas evaluadas.

Interpretación:
  • La accuracy estricta mide el acuerdo pleno con el clasificador.
  • La accuracy permisiva incluye los casos limítrofes (verde + amarillo). Es útil cuando el amarillo se interpreta como "no incorrecto".
  • La tasa de error mide desacuerdos claros del cardiólogo con la predicción del clasificador.
Desglose por clase predicha
$$\text{Accuracy}_{estricta}(k) = \frac{N_{verde,k}}{N_k} \times 100\%$$
Donde: $k$ = clase predicha por el clasificador (por ejemplo NORMAL, PAC, NSR, AFIB); $N_{verde,k}$ = ventanas verdes emitidas por el cardiólogo sobre predicciones de clase $k$; $N_k$ = total de ventanas donde el clasificador predijo $k$. Análoga para permisiva y error rate por clase.

Métricas de valoración de las notas clínicas

{{ metricas_notas.interpretacion }}

Distribución del veredicto global
$$P(V_g = c) = \frac{N_c^{med}}{N_{eval}^{med}} \times 100\%$$
Donde: $V_g$ = veredicto global sobre la nota; $c \in \{correcta, parcial, errónea\}$; $N_c^{med}$ = número de notas donde este cardiólogo emitió el veredicto $c$; $N_{eval}^{med}$ = total de notas evaluadas por este cardiólogo.
Promedios Likert (escala 1–7)
$$\bar{L}_d^{med} = \frac{1}{N_{eval}^{med}} \sum_{i=1}^{N_{eval}^{med}} L_{d,i}$$
Donde: $d \in \{exactitud, coherencia, utilidad\}$; $L_{d,i}$ = puntuación Likert (1 = muy pobre, 4 = aceptable, 7 = excelente) que este cardiólogo otorgó en la dimensión $d$ para su $i$-ésima evaluación. Un promedio alto (≥ 5) sugiere que el cardiólogo aprueba la calidad de las notas del LLM.
Porcentaje promedio de subrayado por color
$$\overline{\%}_c^{med} = \frac{1}{N^{med}_{marc}} \sum_{i \in E^{med}_{marc}} \frac{\text{chars}_{c,i}}{\text{chars}_{total,i}} \times 100\%$$
Donde: $c \in \{verde, amarillo, rojo, sin\_marcar\}$; $E^{med}_{marc}$ = subconjunto de evaluaciones de este cardiólogo que incluyen subrayado; $N^{med}_{marc} = |E^{med}_{marc}|$; $\text{chars}_{c,i}$ = caracteres marcados con color $c$ en la evaluación $i$; $\text{chars}_{total,i}$ = caracteres totales de la nota en la evaluación $i$.
