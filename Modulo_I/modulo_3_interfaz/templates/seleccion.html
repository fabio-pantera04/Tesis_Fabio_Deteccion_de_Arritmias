Seleccione una señal para evaluar

Cinco señales ECG están disponibles para evaluación. Cada una corresponde a 60 segundos de registro en derivación II a 250 Hz. Se recomienda evaluar las cinco para que el reporte estadístico tenga cobertura completa.

Guía de evaluación

Cómo evaluar cada señal

Cada señal se evalúa en tres partes obligatorias. Lea esta guía antes de comenzar. Puede volver a esta página en cualquier momento desde el enlace Señales del menú superior.

1

Semáforos de latidos (60 ventanas de 1 segundo)

Para cada segmento de 1 segundo, el clasificador automático predice si el latido es NORMAL (latido sinusal esperado) o PAC (contracción prematura auricular). Su tarea es validar cada predicción marcando un semáforo:

  • VERDE Estoy de acuerdo con la predicción del clasificador.
  • AMARILLO No estoy seguro, es un caso limítrofe o ambiguo.
  • ROJO No estoy de acuerdo, la predicción es incorrecta.

Nota: pase el cursor sobre el trazado para ver el tiempo exacto (segundos) y el voltaje (mV) de cada punto. Use el zoom del navegador (Ctrl + rueda) si necesita inspeccionar detalles finos del trazado.

2

Semáforos de ritmo (15 ventanas de 4 segundos)

Para cada segmento de 4 segundos, el clasificador predice si el ritmo es NSR (ritmo sinusal normal) o AFIB (fibrilación auricular). Aplique el mismo criterio de semáforo verde/amarillo/rojo según su acuerdo con la predicción.

3

Evaluación de la nota clínica (tres sub-tareas)

Debajo de las señales aparecerá una nota clínica generada automáticamente por un modelo de lenguaje. Debe evaluarla en tres partes:

3.1. Subrayado por segmento (obligatorio, nota completa)

Seleccione con el cursor cada segmento de texto y márquelo con el color correspondiente:

  • Verde Este texto es clínicamente correcto.
  • Amarillo Este texto es parcialmente correcto o ambiguo.
  • Rojo Este texto es incorrecto o incompatible con la señal.

Importante: debe subrayarse la nota completa. No deje segmentos sin marcar. El sistema le mostrará el porcentaje de texto marcado en tiempo real.

3.2. Calificación Likert y veredicto global (obligatorio)

Además del subrayado, califique la nota globalmente con:

  • Veredicto global: semáforo verde / amarillo / rojo sobre la nota completa.
  • Tres escalas Likert (1–7):
    • Exactitud diagnóstica — ¿la nota describe correctamente lo que muestra el ECG?
    • Coherencia terminológica — ¿la terminología es consistente con la práctica clínica estándar?
    • Utilidad clínica — ¿la nota resulta útil para un cardiólogo evaluador?

La escala de siete puntos permite mayor discriminación: 1 = muy pobre, 4 = aceptable, 7 = excelente.

3.3. Comentarios libres (opcional)

Añada cualquier observación adicional que considere relevante: omisiones, correcciones específicas, sugerencias para mejorar el sistema, etc.
