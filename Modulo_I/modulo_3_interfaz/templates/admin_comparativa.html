Comparativa por senal

Vista de cada senal del estudio comparando la etiqueta real de la base de datos (ground truth), las predicciones del clasificador MSM-SC + XGBoost, y los veredictos de los cardiologos evaluadores con las metricas de concordancia derivadas.

Como leer esta vista
  • Etiqueta real: proviene del dataset de origen (CinC2017 anotado por consenso de 3 cardiologos; Icentia11k anotado por especialistas). Es la referencia estandar del estudio.
  • Prediccion clasificador: es la clase que emitio el clasificador dual MSM-SC + XGBoost para cada ventana.
  • Veredicto medico: es el semaforo (verde/amarillo/rojo) que los cardiologos evaluadores emitieron para validar cada prediccion.
